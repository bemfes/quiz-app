# 🧠 Приложение с викторинами

Веб-приложение для прохождения интерактивных викторин. Перед началом теста пользователь может выбрать тему, уровень сложности, количество вопросов и тип ответов. После завершения отображается итоговый результат с количеством правильных ответов.

🌐 [Демо проекта](https://bemfes.github.io/quiz-app/)

## 🛠️ Стек

* React
* TypeScript
* Redux Toolkit
* Tailwind CSS
* Vite

## 🎯 Функционал

* Прохождение интерактивной викторины
* Выбор категории вопросов
* Выбор уровня сложности
* Настройка количества вопросов
* Выбор типа ответов (один правильный ответ или «Верно / Неверно»)
* Загрузка вопросов из Open Trivia Database API
* Подсчет количества правильных ответов
* Отображение итогового результата после завершения викторины
* Возможность начать новую викторину

## 📡 API

Приложение использует [Open Trivia Database API](https://opentdb.com/api_config.php ) для получения вопросов викторин.

## 🚀 Установка и запуск

1. Клонируйте репозиторий

```
git clone https://github.com/bemfes/quiz-app.git
```

2. Установите зависимости

```
npm install
```

3. Запустите проект в режиме разработки

```
npm run dev
```
