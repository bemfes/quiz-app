# About Project

This project is an interactive quiz that uses a question API to create personalized tests. Users can customize survey parameters and complete online quizzes with scoring. Users can select a survey topic from the provided options, difficulty level, number of questions, and answer type.

This project is made using React, Redux Toolkit and TypeScript. Tailwind CSS was used for styling. The API was provided by Open Trivia Database API https://opentdb.com/api_config.php
